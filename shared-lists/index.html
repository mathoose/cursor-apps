One-time setup

Connect a shared room

Lists live in a free Supabase project so both phones see the same room. Until that is connected, nothing is saved to a shared room.

  1. Create a free project at supabase.com.
  2. Open the SQL editor, paste shared-lists/supabase.sql, and run it.
  3. In Project Settings → API, copy the Project URL and the anon public key.
  4. Put both values in shared-lists/config.js and merge that update.

The anon key is public on purpose. A room still asks for its PIN before it opens.
