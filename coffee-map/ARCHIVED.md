# Archived app

**Coffee Map** is hidden from the home screen launcher. Use **[Coffee & Drinks](../coffee-drinks-map/)** for cafes and bars on one map.

- Cafe catalog: **`coffee-drinks-map/coffee.json`** (not `places.json` here).
- Location sync: `node philly-dates/sync-google-locations.js --catalog coffee` (see **[coffee-drinks-map/LOCATIONS.md](../coffee-drinks-map/LOCATIONS.md)**).
- This folder remains on GitHub Pages for direct URLs; `coffee-map-v1` localStorage is unchanged if you open it manually.
