Settings

Set up alerts

Jot can’t buzz your phone once it’s closed. Build these two Shortcuts once and Jot hands timers to Clock and reminders to Apple Reminders, so they reach your lock screen. Until then, timers and reminders only show while Jot is open.

Timers
How to build the timer Shortcut
  1. Open the Shortcuts app and tap +.
  2. Tap the name at the top, choose Rename, and call it Jot Timer.
  3. Search the actions for Start Timer and add it.
  4. Tap the amount of time in that action and choose Shortcut Input. Leave the unit on minutes.
  5. Tap Done.

Jot sends one number: how many minutes.

Your phone should jump to Shortcuts and Clock should start counting. If it does, switch this on. Then come back to Jot yourself.

Reminders
How to build the reminder Shortcut
  1. In Shortcuts, tap + and name the new one Jot Reminder.
  2. Add Split Text. Set the text to split to Shortcut Input and leave it on New Lines.
  3. Add Get Item from List. Leave it on First Item. This is the note.
  4. Add Get Item from List again. Change it to Last Item, then tap the list it reads from and choose Split Text. This is the time.
  5. Add Add New Reminder. For the reminder’s name, choose the first Item from List.
  6. Open that action’s extra options, turn on an alert at a time, and for the time choose the second Item from List.
  7. Tap Done.

Jot sends two lines: your note, then the time written like “November 26, 2026 at 9:00 AM”. The wording of these steps can differ a little between iOS versions.

A reminder called “Jot test” should appear in Reminders and alert you in 2 minutes. If it does, switch this on.

Backup

Everything in Jot stays on this phone. Export a copy to keep it safe or move it.
